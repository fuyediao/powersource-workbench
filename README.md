# PowerSource Workbench

PowerSource Workbench is the group-wide desktop workspace. The first release contains the desktop, local search, settings, and invitation-only account access without CRM modules or the previous permission model.

GeoCRM on `powersource.app` is a behavior reference only. Workbench runs on its own `powersource.work` VPS.

## Repository layout

- `desktop/`: Electron, React, Tailwind CSS, local search, settings, and direct Supabase Data API access.
- `backend/`: Go API (`workbench-api`). Password grants, invitation creation, and Home widget proxies (`/start/*`) stay here.
- `supabase/`: Database migrations for Workbench profiles and leftover customer rows. Mail and Calendar are not stored here.
- `scripts/`: Ignored environment generation, VPS deploy, and the one-time administrator bootstrap.
- `web/`: Public static pages. `web/download/` is the installer page for `https://binovo.ai/download`. Vercel serves this folder and rewrites `/` to `/download`.

## Authentication

There is no public registration, social login, magic link, one-time-password, or email login. The desktop posts a username and password to the Go API on `https://api.powersource.work`. Go loads `work_profiles` by username and completes the Auth password grant. Workspace rows are then read and written from the desktop against `https://supabase.powersource.work` with that user JWT, the same split GeoCRM uses.

Invitation creation also goes through Go. The desktop never receives a secret or service-role key. Workbench tables do not store email.

## Setup

1. Keep the ignored root `.env.vps` pointed at the `powersource.work` host.
2. Run `python scripts/configure-local-env.py` to create `desktop/.env` and `backend/.env` from the Workbench Supabase stack on that VPS. Use `--replace` only for files previously generated by this script.
3. Deploy with `python scripts/deploy-remote.py`. The script builds `workbench-api` on the VPS, points nginx `api.powersource.work` at `127.0.0.1:3001`, and applies the profile migration when the tables are missing.
4. After `download.powersource.work` resolves to the same host, run `python scripts/setup-download-nginx-vps.py`. Upload packaged installers with `python scripts/upload-desktop-release-vps.py` into `macos-m|macos-i|windows/beta0.1.0/`.
5. Run `python scripts/bootstrap-admin.py --username ps0000 --password <password>` once. The username and password live in Auth, not in desktop or local `.env` files.
6. Run `npm install --prefix desktop`, then `npm run dev:electron` from the repository root. Sign in as `ps0000`. Login goes to the VPS API, not a local Go process.

## Deployment requirement

The public Supabase endpoint must accept the configured publishable key and expose Auth and Data API routes. Public registration must remain disabled.
